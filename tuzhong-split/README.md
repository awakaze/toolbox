# tuzhong-split — 图种分离工具

把"图种"（图片与压缩包合并在一起的文件）拆分回两个独立文件：原始图片 + 压缩包。

- 命令行版（`split.py`）纯标准库；图形界面（`gui.py`）依赖 `tkinterdnd2` 实现拖拽导入
- 通过 `mmap` 内存映射扫描 zip / rar / 7z 特征码，支持超大文件（GB 级）且不吃内存
- 分块边读边写（每次 4MB），避免一次性读入整个文件
- **无任何选项**：分离结果永远**覆盖**同名旧产物（多层嵌套、同名产物直接以新换旧）
- 覆盖是安全的：先写临时文件、全部成功后再原子改名，中断不会留下 0 字节/半成品，也不会破坏旧结果
- 同一目标跨进程互斥（可同时开多个窗口处理不同文件），写前预检磁盘剩余空间

## 使用方法

### 图形界面（推荐）

```bash
cd tuzhong-split
pip install -r requirements.txt
python gui.py
```

- 直接从资源管理器把文件或文件夹**拖入窗口**即可加入列表；也可用按钮：「添加文件」多选、「添加文件夹」递归扫描其中的图片文件
- 列表内可多选后「移除选中」，或「清空列表」重新选择
- 「开始分离」后后台处理，界面实时显示总体进度、单个文件进度与日志，不卡界面
- 输出文件生成在源文件同目录，文件名带 `_分离出的图片` / `_分离出的压缩包` 后缀

### 命令行

```bash
cd tuzhong-split

# 处理单个文件（支持通配符）
python split.py 10GB图种.jpg

# 扫描当前目录及所有子文件夹的全部文件
python split.py -r

# 只扫描指定扩展名（可多个）
python split.py -r *.jpg *.png
```

## 工作原理

1. 对文件做 `mmap` 只读映射，依次查找压缩包魔数：
   - `PK\x03\x04`（zip）
   - `Rar!\x1A\x07`（rar）
   - `7z\xBC\xAF\x27\x1C`（7z）
2. 找到特征码且位置大于 0 时，按位置切开：
   - `0 ~ 特征码位置` 写入 `<原名>_分离出的图片.<原扩展名>`（无扩展名默认 `.jpg`）
   - 特征码位置到文件末尾写入 `<原名>_分离出的压缩包.<zip|rar|7z>`
3. 同名旧产物会被**直接覆盖**；写入先落到临时文件（`*.part`），全部成功后再原子改名，因此中断不会留下半成品
4. 原文件始终保持不动

自动跳过的情况（均为兜底，无需也无法配置）：脚本自身、空文件、未找到特征码的文件、磁盘空间不足、同一目标正被其他进程写入、上次中断遗留的 `*.part` 临时文件。

## 打包为 exe

```bash
cd tuzhong-split
pip install pyinstaller
pyinstaller tuzhong-split.spec
```

产物为 `dist/tuzhong-split.exe`，双击即可运行，无需安装 Python。

## 注意

- 输出文件生成在源文件同目录，文件名带 `_分离出的图片` / `_分离出的压缩包` 后缀
- `-r` 递归扫描以**当前工作目录**为起点，请在目标目录下运行

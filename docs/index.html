Toolbox 小工具集

存放各种实用小工具的仓库，每个工具一个独立文件夹，互不依赖、各自自包含。

5 个工具 · Python / Tampermonkey · MIT License

firefly-music-parser

→

为 Firefly 博客主题的本地音乐模式一键解析音频标签、封面、歌词，并生成播放列表配置。

Python requests · mutagen

moe-icp-ids

→

从萌ICP 分页抓取当前可认领的萌号（备案号），去重排序后导出为文本文件，供选号使用。

Python requests

trae-checkin

→

Trae CN 每日自动签到领积分：自动读取本机登录态，支持多账号、限流重试与失败通知推送。

Python pycryptodome（可选）

steam-booster-tool

→

Steam 补充包工具箱：按宝石做包利润筛选，管理拉黑 / 收藏 / 队列，队列游戏到点自动做包。

Tampermonkey 无依赖

tuzhong-split

→

图种分离工具：把图片与压缩包合并而成的文件，按压缩包特征码拆回图片和压缩包两个文件。

Python 纯标准库

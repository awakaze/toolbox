萌ICP 萌号提取

从 萌ICP 分页抓取当前可被认领的萌号（备案号 ID），去重排序后导出为文本文件，供你在萌ICP 上选号使用。

Python requests
查看源码 完整 README

功能特性

功能说明
批量抓取自动遍历 .moe 分页（默认前 10 页），用正则提取 join.php?id=… 中的萌号
去重排序合并所有页面结果，去重并按从小到大排序
结果导出保存为纯文本 moe_ids.txt，每行一个萌号，可直接复制使用
礼貌请求内置 0.5s 请求间隔，避免触发风控

安装

cd moe-icp-ids
pip install -r requirements.txt

使用

python3 crawl_moe_ids.py

脚本会依次请求 https://icp.gov.moe/moeid.php?p=N（N = 0..9），随后把验证可用的萌号按升序写入当前目录的 moe_ids.txt。

自定义抓取页数

默认抓取 10 页。如需调整，直接修改脚本里的取值范围（一共只有 10 页）：

for p in range(10):   # 改这里，例如 range(20)

输出示例

moe_ids.txt 每行一个萌号：

20260254
20260257
20260259

说明

  • 依赖 requests；脚本仅此一个第三方库，无需 ffmpeg 等外部程序
  • 抓取目标为公开页面，仍请控制频率、避免对站点造成压力，正式大量使用前建议先小范围试跑
  • 萌号可用性以萌ICP 站点实时状态为准，脚本结果仅代表抓取那一刻的页面内容

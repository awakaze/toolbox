Steam 补充包筛选制作

运行在 Steam 社区「补充包制作」页与游戏商店详情页的 Tampermonkey 用户脚本：按宝石做包利润筛选补充包，支持拉黑 / 收藏 / 做包队列 / 自动作包列表管理，自动列表里的游戏到点自动制作。价格取自官方 Steam 接口，并按 Steam 新版市场手续费计算税后收入。

Tampermonkey 无依赖 单文件脚本
安装用户脚本 查看源码 完整 README

功能特性

  • 利润筛选：逐游戏展示 做包成本 / 3 张卡牌税后收入 / 补充包税后卖价 / 利润率 / 制作量 / 上次制作
  • 查询架构：每游戏 2 个请求起（卡牌数 >10 时自动翻页），全部走 search/render?norender=1（JSON，sell_price 为钱包币种精确分值）
  • 利润保护：默认不做利润低于 10% 的补充包；队列 / 自动列表里对单个游戏勾选「强制」即可绕过阈值
  • 列表管理：未分类可在 拉黑 / 收藏 / 做包队列 / 自动作包列表 之间流转，支持「一键拉黑未分类」
  • 队列一键制作：「一键制作（队列可做 N）」立即把队列里可做的游戏做掉
  • 自动做包：加入自动做包列表时立即尝试一次；「自动做包」复选框为轮询总开关，到点实时查价 → 利润闸门 → 串行制作，结果走系统通知
  • 防风控：所有价格请求严格串行 + 可配间隔，命中限流自动退避重试，单游戏失败即标记跳过、绝不卡死
  • 跨页持久化：列表、配置、价格缓存、退避状态存浏览器端 GM 存储，刷新 / 换天保留

安装

  1. 浏览器安装 Tampermonkey（Chrome / Edge / Firefox）
  2. 点击上方「安装用户脚本」按钮（或打开 Tampermonkey 管理面板 → + 新建脚本 → 全选粘贴脚本内容），保存
  3. 登录 Steam 社区，打开补充包制作页，工具栏即出现在页面上

利润是什么

利润指「自己做包 → 拆卡卖掉」这条路线的利润率（不是买别人的包来拆）：

成本   = 做一个包所需宝石数 ÷ 1000 × 一袋宝石价（市场价或自定义价）
收入   = 拆包得 3 张普通卡，每张按市场最低在售价扣手续费后到手
         （逐卡单独计税再平均 × 3；手续费按 2025-12 新规）
利润率 = (3卡税后收入 − 成本) ÷ 成本
  • 补充包卖价列是「直接卖整个包」的税后所得，仅供两条路线对比，自动制作只按拆卡利润率决策
  • 已含全部税费；不含市场价格波动与挂单时间成本

自动作包工作方式

游戏加入「自动做包列表」
  → 立即尝试做一次（不可做 / 冷却中则失败，交给轮询）
  → 「自动做包」开关开启时，每 轮询min 分钟检查一次（纯本地定时，零请求）
  → 游戏冷却到点：
       实时查价（2 请求）→ 利润闸门（"强制"绕过）→ 串行制作
  → 结果通知：
       做成     → 批次汇总系统通知（同一 tick 做成几个合并为一条）
       没到 CD  → 完全静默
       宝石不足 → 通知一次 + 自动取消「自动做包」勾选（手动勾选恢复轮询）
       其他失败 → 退避 5→15→30 分钟重试（不通知），放弃后通知一次，24 小时后自动恢复

脚本运行在浏览器页面里，做包页标签页需保持打开；做成后该游戏本会话不再重做，页面刷新后按 Steam 新冷却继续。

手续费模型

Steam 新版市场规则：卖家设定到手价 R，买家支付 P = R + fee(R)；手续费按到手价计算，一笔交易拆两笔独立费用，各自向下取整到分、且每笔不低于最低额：

交易费 = max(minFee, floor(到手价 × 5%))     // Steam 交易费
分成费 = max(minFee, floor(到手价 × 10%))    // 卡牌 / 补充包属 Steam 本体

【2025 年 12 月起】单笔最低手续费提高为 $0.01 等值：国区 = ¥0.07（旧值 ¥0.01 已失效）。

脚本由市场返回的买家支付价 P 精确反解到手价 R，并逐卡单独计税后再取平均。反解校验示例（人民币区，minFee = 7 分）：

买家支付价手续费到手
¥0.210.07+0.07¥0.07
¥0.740.07+0.07¥0.60
¥1.000.07+0.08¥0.85
¥1.080.07+0.09¥0.92

常见问题

进页面后状态一直「正在读取补充包数据…」？

脚本依赖页面全局 CBoosterCreatorPage.sm_rgBoosterData 异步加载；若持续无数据，刷新页面或确认 Tampermonkey 已启用并匹配当前网址。

为什么当前列表很久才出价格？

为防 Steam 卡风控，脚本强制串行 + 间隔请求，列表越长越久。再次访问时多数价格走缓存会明显加快，请求间隔可在控制条调整。

自动做包没做某些游戏？

被跳过的通常是：冷却未过、利润低于阈值、卡牌不可交易、或尚未算出利润。勾选该游戏「强制」可强制制作（若宝石充足）。

为什么自动做包没反应？

确认三点：游戏在「自动做包」列表里、自动做包复选框已勾选、做包页标签页保持打开。

失败的自动制作会一直重试吗？

可恢复错误按 5→15→30 分钟退避重试，退避进度跨页面刷新保留；连续失败 4 次后放弃并系统通知，24 小时后自动恢复监控。
